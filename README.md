Fullscreen Pro Calculator 

A sleek, modern, and AI-powered calculator application designed for a distraction-free, productive experience. This calculator goes beyond simple arithmetic by integrating directly with Google's Gemini API to provide intelligent mathematical assistance.

Key Features

AI-Powered Math Tools: Access a suite of AI features via the sidebar:

Explain: Get step-by-step breakdowns of your calculations.

Solve: Understand complex operations with detailed logic.

Quiz: Generate 3-question math quizzes based on your current input.

Story/Word Problems: See your math transformed into fun, creative stories.

Convert & Formula: Perform unit conversions and find relevant mathematical formulas.

Dynamic Theming: Choose from 50 unique HSL-based color skins to match your preference.

Smart History: Review your previous calculations in a compact, scrollable side panel.

Keyboard Support: Use your physical keyboard to enter numbers and operations seamlessly.

Cinematic UI: Includes a 3-second startup loading animation for a premium feel.

Responsive Design: Fully styled with Tailwind CSS for a modern, blur-effect aesthetic.

Getting Started

To get this project running in your local environment or via GitHub Pages:

Clone or Download this repository.

Open calculator.html in your web browser.

Configure API Key:

When you first load the app, click the Key (🔑) icon in the top-right corner.

Paste your Google Gemini API Key.

The app stores this key locally in your browser's localStorage. It is never sent to any server other than Google's secure API endpoint.

Security Note

Important: This project is designed to be safe for open-source sharing because it does not hardcode your API key. Please ensure that you do not commit any files containing sensitive credentials to your repository. The key is managed entirely on the client side by the individual user.

Technologies Used

HTML5 / CSS3: Structure and layout.

Tailwind CSS: Styling and design system.

JavaScript: Application logic and API integration.

Google Gemini API: Powering the AI features.
